# Automasi Terjadwal

Buka lewat ikon jam di footer sidebar, palet perintah ("Automasi terjadwal"), atau `#/automation`.

- **Tugas baru:** isi nama, pilih project (atau tanpa project), tulis prompt, lalu jadwal:
  - **Harian:** jam (HH:MM) dan hari (kosong = setiap hari);
  - **Setiap beberapa menit:** 5–10080;
  - **Sekali:** tanggal dan jam di masa depan.
- **Hanya saat Zandor terbuka.** Bila aplikasi tertutup pada jam yang dijadwalkan, tugas dijalankan **sekali** saat aplikasi dibuka lagi.
- Setiap kali jalan, Zandor membuat **sesi baru** (berjudul ⏱ nama tugas) di project, mengirim prompt, dan memberi tahu Anda
  saat mulai, selesai, **menunggu persetujuan**, atau gagal. Buka hasilnya dengan **Buka sesi terakhir**.
- **Izin tidak disetujui otomatis.** Bila agent perlu mengedit berkas atau menjalankan perintah, sesi menunggu Anda.
- **Notifikasi sistem:** izinkan saat diminta (atau lewat tombol "Izinkan notifikasi"). Tanpa izin, pemberitahuan tetap muncul di dalam aplikasi.
- Tombol **Jalankan sekarang** menjalankan tugas segera; **Aktif** mematikan/menyalakan jadwal tanpa menghapus.
