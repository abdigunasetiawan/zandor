# Project, sesi, dan file

- **Tambah project:** tombol **+** di sidebar → pilih folder. Folder yang sama tidak digandakan. Daftar project disimpan di
  perangkat ini (`projects.json`).
- **Ganti nama / lepas:** klik kanan (atau tombol ⋯) pada project. "Lepas dari daftar" tidak menghapus folder maupun sesinya.
- **Sesi:** tombol **+** pada project membuat sesi baru; grup **Chat (tanpa project)** untuk percakapan tanpa folder.
  Klik kanan sesi untuk ganti nama atau hapus (dengan konfirmasi).
- **Cari:** kolom pencarian menyaring judul sesi di semua grup.
- **Tab sesi:** sesi yang dibuka tampil sebagai tab di atas panel Chat (maks 12, tersimpan).
- **Tab Files:** pohon file project aktif; klik berkas untuk membukanya di panel Dokumen.
- Status engine dan versi aplikasi ada di footer sidebar. Bila engine bermasalah, tombol **Coba lagi** memulai ulang.
