# ADR-007 — Tidak ada OAuth langganan Anthropic

- **Tanggal:** 13-11-2026
- **Status:** Diterima

## Keputusan

Tidak ada OAuth langganan Anthropic. Login provider hanya lewat jalur resmi OpenCode

## Alasan

Anthropic melarang OAuth langganan di pihak ketiga (Feb 2026)

> Dipecah dari tabel `docs/decisions.md` saat Fase 1 tanpa perubahan isi. Perubahan berikutnya dicatat
> sebagai ADR baru yang merujuk ADR ini.
