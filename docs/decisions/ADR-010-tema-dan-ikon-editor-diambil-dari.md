# ADR-010 — Tema dan ikon editor diambil dari Open VSX, bukan VS Code Marketplace

- **Tanggal:** 13-11-2026
- **Status:** Diterima

## Keputusan

Tema dan ikon editor diambil dari Open VSX, bukan VS Code Marketplace

## Alasan

Ketentuan Marketplace membatasi penggunaan ke produk Microsoft
